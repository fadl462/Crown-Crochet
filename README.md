# Crown & Crochet — Premium Salon Website

A premium, responsive static website concept for a crochet dreadlock specialist in Middelburg, Mpumalanga, South Africa.

## Included
- Premium black / cream / rose-gold visual system
- Responsive navigation and mobile menu
- Home, About, Services, Gallery, Testimonials, Booking and Contact pages
- Gallery lightbox
- Working prototype booking, contact and testimonial forms using browser storage
- Local SEO metadata and HairSalon JSON-LD
- Sitemap + robots.txt
- Decap CMS scaffold in `/admin`
- Temporary AI-generated visual assets in `/assets`

## Important launch replacements
1. Replace the working salon name with the client's official name.
2. Replace placeholder phone, email, WhatsApp, address and social links.
3. Replace temporary AI visuals with approved client photography.
4. Replace working prices with the approved price list.
5. Connect booking to the salon's preferred booking platform or custom backend.
6. Configure Decap CMS GitHub OAuth before enabling `/admin` for staff.

## GitHub Pages
This project is static and can be hosted directly on GitHub Pages. No build command is required.

## Brand direction
Luxury editorial, specialist craftsmanship, warm hospitality, confident African beauty, restrained rose-gold accents and strong conversion CTAs.
